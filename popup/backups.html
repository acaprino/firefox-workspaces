A tab is added to the active workspace. Workspace restores create new workspaces. Open tabs are kept. Original containers must still exist.

Backup settings and file import

Backups connect to this Firefox profile automatically and are enabled by default. Changes are saved after 6 seconds, with a check every 5 minutes. JSON files in the profile are the only backup archive.

Older JSON versions are removed only after a successful backup. Default: 50 versions.

The local helper must be installed once for this Firefox profile. File backups contain addresses and titles, without cookies, passwords, page history or form contents. Pinned tabs are outside workspace backups.
